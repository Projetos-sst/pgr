# Contract — Server Actions (Document GED)

Todas envolvidas por `officeAction(operation, fn, { audit })` → `ActionResult<T>` (`{ok:true,data}` | `{ok:false,error}`). Gate `requireOfficeStaff()` (owner/collaborator; `client`→FORBIDDEN). Tenant de `ctx.tenantId`, nunca do input. Escritas com `audit: true` + `auditedTenantWrite` no repo. Arquivo `src/shared/server/actions/documents/{documents,folders}.ts`.

## Documentos — `documents.ts`

| Action                                   | operation                         | Entrada                                                                                                               | Saída (`data`)                                                                                                 | Erros                                                                                 |
| ---------------------------------------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `listDocumentsAction(params)`            | `documents.documents.list`        | `{ folderId?: uuid\|null, search?, docType?, validity?: 'ok'\|'due_soon'\|'expired'\|'no_expiry', page?, pageSize? }` | `{ rows: DocumentListItem[], total, kpis: DocumentKpis, breadcrumb: BreadcrumbItem[], folders: FolderNode[] }` | —                                                                                     |
| `getDocumentAction(id)`                  | `documents.documents.get`         | `id: uuid`                                                                                                            | `DocumentDetail`                                                                                               | `NOT_FOUND` (404, incl. cross-tenant)                                                 |
| `createDocumentAction(formData)`         | `documents.documents.create`      | `FormData` (file + metadados)                                                                                         | `DocumentDetail`                                                                                               | `VALIDATION` (tipo/tamanho/obrigatório), `FK_NOT_FOUND` (pasta inválida), `DUPLICATE` |
| `updateDocumentAction(id, patch)`        | `documents.documents.update`      | `id` + `updateDocumentSchema`                                                                                         | `DocumentDetail`                                                                                               | `NOT_FOUND`, `VALIDATION`, `FK_NOT_FOUND`                                             |
| `addDocumentVersionAction(id, formData)` | `documents.documents.add_version` | `id` + `FormData` (novo file)                                                                                         | `DocumentDetail` (nova versão)                                                                                 | `NOT_FOUND`, `VALIDATION`, `DUPLICATE` (corrida de versão)                            |
| `moveDocumentAction(id, folderId)`       | `documents.documents.move`        | `id` + `{ folderId: uuid\|null }`                                                                                     | `DocumentDetail`                                                                                               | `NOT_FOUND`, `FK_NOT_FOUND`                                                           |
| `deleteDocumentAction(id)`               | `documents.documents.delete`      | `id: uuid` (qualquer versão)                                                                                          | `{ groupId, deletedVersions }`                                                                                 | `NOT_FOUND`                                                                           |

**Exclusão (grupo inteiro)**: `deleteDocumentAction(id)` resolve o `document_group_id` da linha, remove **todas** as versões do grupo numa transação `withOrg`, e **após o commit** remove os objetos do Storage em best-effort (falha logada, não reverte). 404 se o id não existe/é de outro escritório.

## Pastas — `folders.ts`

| Action                           | operation                  | Entrada                                               | Saída                                                     | Erros                                                                |
| -------------------------------- | -------------------------- | ----------------------------------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------- |
| `createFolderAction(input)`      | `documents.folders.create` | `createFolderSchema` `{ name, parentId?:uuid\|null }` | `FolderNode`                                              | `VALIDATION`, `DUPLICATE` (nome irmã), `FK_NOT_FOUND` (pai inválido) |
| `renameFolderAction(id, name)`   | `documents.folders.rename` | `id` + `renameFolderSchema`                           | `FolderNode`                                              | `NOT_FOUND`, `VALIDATION`, `DUPLICATE`                               |
| `listFolderTreeAction(parentId)` | `documents.folders.tree`   | `parentId?: uuid\|null`                               | `{ folders: FolderNode[], breadcrumb: BreadcrumbItem[] }` | —                                                                    |

**Notas**: `revalidatePath("/documents")` nas mutações. `create`/`add_version` recebem `FormData` (não objeto) por transportarem binário. Validação zod/`validateFile` **antes** de qualquer gravação. Nenhuma action retorna entidade Drizzle crua com `storage_path` para UI de lista (só `DocumentDetail` expõe `storagePath`).
